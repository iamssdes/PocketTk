PocketTk
========

1. Unpack the archive anywhere you like to keep it (for example ~/Apps), then:
2. ./install.sh        adds PocketTk to your application menu and puts "pockettk" in ~/.local/bin
   or just run ./pockettk-gui to open the window without installing.

./pockettk is the command line tool (build, run, doctor, ...), using the same bundled Python.

The window is drawn with Qt WebEngine, which is inside this folder. It needs the usual desktop libraries; on a very bare
system install them first. Debian / Ubuntu:
    sudo apt install libegl1 libgl1 libxkbcommon-x11-0 libxcb-cursor0 libxcb-icccm4 libxcb-keysyms1 libxcb-shape0 libxcb-image0 libxcb-render-util0 libnss3 libasound2t64 libopus0 libxcomposite1 libxdamage1 libxrandr2 libxtst6 libxkbfile1 libdbus-1-3 libfontconfig1
(libasound2 instead of libasound2t64 on older releases). Errors are written to the terminal you started it from.

The first time PocketTk starts it installs what it needs (a Java JDK and Google's Android build tools) into ~/.pockettk.
You are asked to accept Google's Android SDK license; no root password is needed.

Prefer one file? Get the .AppImage instead: make it executable (file manager: right-click > Properties > Permissions >
Allow executing) and double-click it. It needs FUSE (Ubuntu 22.04+: sudo apt install libfuse2t64, or fuse3).
